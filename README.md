## Design and User Experience

Primary Color: Navy Blue (#1E3A8A)– Builds trust and confidence. 

Secondary Color: Emerald Green (#10B981) - Represents innovative and growth  

Background: White (#FFFFFF) - Keeps the design clean and user-friendly

 Heading Font: Poppins - because, it has a modern, bold and professional look

The website will be simple to use and have a neat layout. To make sure it functions properly, a responsive layout will be used. The design will prioritize ease of use, quick information access, and gaining potential customers' trust.
